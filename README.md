# General Sports Desk

General Sports Desk is an open-source workspace for building transparent, reusable sports-data tools across leagues and competitions.

## Status

This repository is intentionally starting with a clean history. No retired-project source code, production data, credentials, provider-derived datasets, or proprietary model logic has been imported.

Initial development will focus on public-safe foundations:

- provider-neutral schemas and normalization;
- documented ingestion interfaces;
- synthetic fixtures and reproducible tests;
- accessible dashboards and visualizations;
- clear provenance and licensing boundaries.

## Safety and data policy

- Never commit credentials, environment files, private keys, production databases, or personal data.
- Use synthetic fixtures unless a dataset's license explicitly permits redistribution.
- Document the source and license of every external dataset or bundled asset.
- Treat provider terms, rate limits, and attribution requirements as product requirements.
- Report security concerns according to [SECURITY.md](SECURITY.md).

## Contributing
