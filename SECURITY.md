# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability, exposed credential, or privacy concern. Use GitHub's private vulnerability reporting feature for this repository.

Include the affected component, reproduction details, potential impact, and any suggested mitigation. Do not include live credentials or private user data in the report.

## Credential policy

The project must not contain live API keys, tokens, passwords, private keys, production databases, or copied environment files. Examples must use clearly fake placeholders, and tests must use synthetic fixtures.
