# Contributing

Thank you for helping build General Sports Desk.

## Ground rules

1. Start from this repository's clean history; do not merge or copy an archived application's Git history.
2. Do not submit credentials, personal data, production logs, databases, or private league identifiers.
3. Use synthetic test fixtures unless redistribution rights for real data are documented.
4. Document provider terms, attribution, rate limits, and licensing implications with each integration.
5. Keep provider-specific behavior behind a small, testable adapter interface.
6. Add tests and concise documentation for behavior changes.

## Before submitting a change

- run the project's available formatter, lint, test, and secret-scanning checks;
- confirm generated files and local data are excluded;
- verify any copied code or assets are compatible with the repository license;
- explain external data provenance in the pull request.
